Assay

Tests whether a published index measures what it says it measures. Named for the metallurgical test that tells you what an ore is actually made of, rather than what the seller called it.

Nothing leaves your browser. The CSV is parsed and analysed on this page. There is no server, no account and no upload — you can load this file from disk with the network off and it still works.

1 · Your data

One row per entity (country, university, company), one column per sub-score, plus whatever identifier and published-score columns the index carries. Paste it, or try a worked example.

2 · Confirm what each column is

This step is not automatic on purpose. Guessing which columns are sub-scores and which are identifiers is ambiguous for an arbitrary file, and a wrong guess produces a confidently wrong report — which is the exact failure this tool exists to catch in other people's work. Two minutes here beats a clean-looking answer about the wrong columns.

Do these sub-scores share construction?

Tick this if any pillar is an input to another — V-Dem's liberal, participatory, deliberative and egalitarian indices each incorporate the electoral democracy index, so four of five columns contain the fifth. Columns like that would correlate if the world contained no pattern whatsoever. When this is ticked, a dimensional collapse is not reported as a finding, because it is arithmetic rather than evidence.

What this is not. It is not a general statistics tool. It answers five questions about data shaped like a published index and nothing else. It cannot tell you an index is wrong — only whether its own structure supports the claims made for it.

The same five checks Assay's Python engine runs, ported to the browser and verified against it: tools/conform_browser.py compares both over four indices and fails on disagreement beyond 1e-9 wherever they do the same arithmetic. Where the page draws its own random numbers (parallel analysis, the rank envelope) it cannot match numpy's draws, so the retained count must agree and the envelope's summary must land within a tolerance measured from numpy's own seed-to-seed variation.
